## 🚀 اجرا

### ۱) نسخه دسکتاپ ویندوز (بدون هیچ پیش‌نیاز)
```
NeuroScanAI_Ultra_v4_Erfan_Alikhani.exe  → دابل کلایک
```
* ویندوز ۱۰/۱۱ (x64) — هیچ پایتون، OpenCV یا DLL جانبی لازم نیست
* ۶ اسکن نمونه تعبیه‌شده در منو (Real MRI / GBM / Benign / Normal / Benchmarks)
* درگ‌اند‌دراپ هر تصویر CT/MRI
* ۶ حالت نمایش: لایه تلفیقی AI / هیت‌مپ / حذف جمجمه / اسکن اصلی / نقشه تقارن / کنتراست CLAHE
* زوم با اسکرول ماوس (۲۵–۴۰۰٪)، روشنایی، کنتراست
* 📏 خط‌کش دیجیتال میلی‌متری (کلیک و درگ)
* 🖼️ خروجی PNG و 🖨️ گزارش HTML با چاپ خودکار

### ۲) نسخه وب + API
```bash
cd NEUROSCAN-AI-python-project
pip install -r requirements.txt
python3 server.py 8080
# http://localhost:8080
```

### ۳) اعتبارسنجی
```bash
python3 tests/test_pipeline.py     # ۱۲/۱۲ مورد، اطمینان ۹۰٪+
python3 tests/test_server_api.py   # تست REST API
```

### ۴) بنچمارک موتور بومی C++17 (بدون پایتون)
```bash
g++ -O3 -std=c++17 -o neuroscan_bench windows-native-exe/neuroscan_bench.cpp
./neuroscan_bench NEUROSCAN-AI-python-project/samples/
# → NATIVE C++17 ACCURACY: 12/12 (100.0%)
```

### ۵) ساخت مجدد EXE
```bat
cd windows-native-exe
python gen_embedded.py     :: بازسازی نمونه‌های تعبیه‌شده + وزن‌های MLP
build_windows_exe.bat      :: ساخت EXE استاتیک
```

## 🧬 مسیر پردازش

```
تصویر CT/MRI
   ↓ جداسازی پنل تکی + خنثی‌سازی رنگ PACS
   ↓ نرمال‌سازی پنجره (صدک ۱ تا ۹۹.۵) → ۵۱۲×۵۱۲
   ↓ حذف جمجمه نسبتی (فرسایش ۰.۱۱۵r + حذف استخوان روشن + برش CSF)
   ↓ CLAHE ۸×۸
   ↓ نقشه عدم تقارن نیمکره‌ای (آینه + تحمل max-pool 11px)
   ↓ تقسیم‌بندی چندنشانه‌ای Z-Score / تقارن / DoG / ناحیه سلار / حفره نکروز
   ↓ ۱۱ وتوی آناتومیک (فلکس، بطن، سلار تیره، حلقه بدون رینگ، فیلامان)
   ↓ رادیومیکس C++17: GLCM ×۴ زاویه، GLRLM، LBP، فرکتال، Skew، Kurt، ContraCorr
   ↓ شبکه عصبی آموزش‌دیده 22 → 64 → 32 → 3
   ↓ اعتبارسنج WHO + مدل عمیق ۵-پاس TTA
   ↓ درصدهای کالیبره‌شده (≥ ۹۰٪) + گزارش بالینی + خروجی PNG/HTML
```
